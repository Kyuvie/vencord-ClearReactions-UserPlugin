**ClearReactions — Vencord user plugin**
Allows you to instantly remove all reactions from a message by holding a modifier key (Shift / Ctrl / Alt) and clicking it.

**Target audience:** Built for server moderators to handle reaction spam

**Permissions:** Requires the Manage Messages permission. Works in guilds only.

**Installation:** https://www.youtube.com/watch?v=3anTy0EdvsE



## Why this plugin?

Discord's built-in "Remove All Reactions" button works, but you gotta right-click, find it in the menu, and deal with extra confirmations. This plugin cuts that down to just a modifier key + click. Way faster when you're dealing with people spamming reactions.

Plus, clearing reactions in bulk becomes kinda satisfying when you can just speed through messages with one click each.

Inspired by **MessageClickActions** — same modifier+click concept, but focused on clearing reactions instead of deleting/editing/replying.
